
의약품 공식 레퍼런스 생성 도구
병원 약물선정위원회 비교표 검토를 위해 식품의약품안전처 허가사항과 건강보험심사평가원 급여약가를 통합 조회하는 Streamlit 도구입니다. 신청의약품과 비교의약품을 여러 함량 품목으로 구성하는 선택형 그룹 관리, 기준일 약가 판정, AI 검토용 JSON 출력을 제공합니다.

심평원 의약품성분약효정보 연동 (msupCmpnMeftInfoService/getMajorCmpnNmCdList)
조회 결과에 분류명(divNm), 일반명(gnlNm), 함량내용(iqtyTxt), 단위(unit) 열을 추가했습니다. 참고용으로 일반명코드(gnlNmCd) 열도 함께 기록합니다.
약가 API 응답에서 약효분류번호(meftDivNo)와 함께 일반명코드(gnlNmCd)를 읽고, 일반명코드로 성분약효 API를 조회합니다.
일반명코드가 없으면 약효분류번호로 조회해 분류명만 채웁니다. 약효분류번호만으로는 같은 분류의 모든 성분이 나오므로 일반명·함량은 확정하지 않습니다.
기존 HIRA_KEY를 그대로 사용합니다. 공공데이터포털에서 의약품성분약효정보조회서비스 활용신청이 별도로 필요합니다. 신청하지 않으면 네 항목은 빈칸이고 API 경고에 오류가 표시됩니다.
결과는 cache_성분약효.json에 캐시합니다. 기존 cache_약효분류.json은 일반명코드를 함께 저장하는 형식으로 바뀌며, 이전 캐시 항목은 첫 조회 때 한 번 다시 조회합니다.
AI 검토용 JSON schema_version 1.3: 품목마다 hira_component(meft_div_no, div_nm, gnl_nm_cd, gnl_nm, iqty_txt, unit)를 추가했습니다.

포장별 약가 전체 표시
식약처 품목 1개에 심평원 약가가 포장(제품코드)별로 여러 개인 경우(예: 에스로반 연고 10g / 450g), 약가를 모두 표시합니다.
약가가 1건이면 기존과 같이 1,309원으로, 여러 건이면 제품코드(와 포장·규격 힌트)별로 줄을 나눠 표시합니다.
약가적용시작일, 판매예정종료일, 심평원제품코드 행도 약가 줄과 같은 순서로 나뉩니다.
8자리 코드로 조회되지 않으면 바코드의 9자리 제품코드로 다시 조회합니다.
결과 화면에 심평원 약가 원본 필드 확인 영역을 추가해, 포장정보가 어느 필드에 있는지 점검할 수 있습니다.
약가 캐시 키가 새로 생겨, 업데이트 후 첫 조회는 심평원 API를 다시 호출합니다.

hira_prices에는 제품코드, 제품명, 포장·규격 힌트, 상한금액, 적용 시작일, 판매 종료일, 심평원 원본 필드(raw)가 들어갑니다.

옵션을 끄면 기존처럼 하나의 일반 조회 목록으로 품목을 관리합니다.

검색 결과 여러 행을 선택해 원하는 그룹으로 한 번에 이동합니다.
그룹 표에서 제품명의 자동 함량 파싱값을 확인하고 직접 수정하거나 품목을 제거합니다.
조회 결과, 비교표 CSV, AI 검토용 JSON에 그룹명과 확정 함량이 함께 기록됩니다.
그룹 비교표에서는 비교의약품을 먼저 표시하고 신청의약품을 맨 오른쪽에 배치합니다.
그룹 옵션은 1. 의약품 검색 상단의 조회 방식 카드에서 켭니다.
사용하지 않는 DUR 엑셀 업로드 및 DUR 결과 탭은 화면에서 제거했습니다.
의약품명·제약사명뿐 아니라 성분명과 주성분 영문명으로 검색할 수 있습니다.
조회 설정의 [전체] 식약처 제공 항목을 켜면 지원 항목과 의미 있는 상세 API 필드를 MFDS_ 열과 JSON에 포함합니다.
EE_DOC_DATA, UD_DOC_DATA, NB_DOC_DATA 등 XML 원문과 빈값은 전체 결과에서 제외합니다.
비교표는 다시 품목 하나당 한 열로 표시하며 신청의약품은 맨 오른쪽에 배치합니다.
RARE_DRUG_YN은 희귀의약품이라는 한글 항목으로 항상 조회 결과에 포함합니다.
핵심 원칙
허가사항은 식약처 상세 API 원문을 함께 보존합니다.
제품 식별은 BAR_CODE 4~11번째 8자리와 mdsCd 앞 8자리 일치를 우선합니다.
약가는 기준일에 유효한 이력 중 적용시작일이 가장 최근인 값을 선택합니다. (2026-10-19 변경) 같은 8자리 코드 아래 포장별 제품코드(mdsCd 9자리)가 여러 개이면, 제품코드마다 이 규칙을 적용해 모두 표시합니다.
코드가 일치하지 않으면 제품명만으로 약가를 확정하지 않습니다.

API 키는 소스나 결과 JSON에 저장하지 않습니다.

Streamlit 배포
Streamlit Community Cloud의 Main file path에는 app.py를 지정합니다. 의존성은 저장소 루트의 requirements.txt에서 설치됩니다. 배포 설정의 Secrets에 아래 값을 등록합니다.

MFDS_KEY = "식약처 서비스키"
HIRA_KEY = "심평원 서비스키"
로컬 실행은 다음과 같습니다.

python -m pip install -e .
streamlit run app.py
출력
출력 JSON은 조회 기준일, 매칭 상태, 식약처 원문/정규화 텍스트, 심평원 현재 약가와 적용기간, 경고를 포함합니다. (2026-10-19 변경) 포장별 약가가 여러 개인 품목은 hira_prices 목록에 전체 약가가 들어갑니다. 이 JSON과 비교표 또는 PPT를 함께 제공하면 검토 지침에 따라 사실관계를 대조할 수 있습니다.

기준일 약가와 검토용 JSON
조회 전에 심평원 약가 기준일을 선택합니다. 앱은 adtStaDd ≤ 기준일 ≤ sellEptDd인 이력 중 적용 시작일이 가장 최근인 약가를 선택하며, 종료일이 비어 있으면 계속 유효한 것으로 처리합니다. 조회 후 AI 검토용 JSON 다운로드를 눌러 비교표 또는 PPT와 함께 사용할 공식 레퍼런스를 저장할 수 있습니다.
